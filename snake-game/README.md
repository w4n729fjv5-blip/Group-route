# Snake

A dependency-free, single-page Snake game. Pure HTML/CSS/JS — no build step.

## Play

Open `index.html` directly in a browser, or serve the folder statically:

```bash
npx http-server snake-game
```

## Controls

- Arrow keys or WASD to steer
- Space to pause/resume
- On touch devices: swipe on the board, or use the on-screen D-pad
- Best score is saved in the browser via `localStorage`
